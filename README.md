# Розсадка в автобусі

Сайт: людина вводить ім'я та прізвище латиницею → обирає місце на схемі (67 місць, як у PDF) → запис з'являється в Google Таблиці. Одна людина = одне місце (перевіряється на сервері за ім'ям+прізвищем, без урахування регістру; одночасні кліки на одне місце захищені блокуванням).

## Підключення Google Таблиці (5 хв)
1. Створи нову Google Таблицю.
2. **Розширення → Apps Script**, встав вміст `Code.gs`, збережи.
3. **Deploy → New deployment → Web app**: *Execute as* — **Me**, *Who has access* — **Anyone**. Дозволь доступ.
4. Скопіюй URL виду `https://script.google.com/macros/s/.../exec`.
5. В `index.html` встав його в `const SCRIPT_URL = '...'`.

Аркуш «Розсадка» створиться сам: колонки Час | Місце | Прізвище | Ім'я | Ключ.
Щоб звільнити місце — просто видали рядок у таблиці.

## Публікація
Будь-який статичний хостинг: Vercel (`vercel deploy` у цій папці), GitHub Pages, Netlify Drop.

## Налаштування
- `SHOW_NAMES` в `index.html` — показувати імена на зайнятих місцях.
- `BLOCKED_SEATS` в `Code.gs` — місця, які не можна обрати (напр. для керівника).
- Після зміни `Code.gs`: Deploy → Manage deployments → Edit → New version.
